# 全局配置

> 这是整个调度框架的**唯一配置入口**。主会话每轮开始读一次本文件，据此决定运行时说明、默认项目、约定文档名、单轮上限。
> 换软件、换项目、调批量，**只改本文件的 frontmatter，不要改提示词**。

## 字段说明

| 字段 | 作用 | 留空后果 |
|---|---|---|
| `agent_runtime` | 记录用的运行时名称，仅说明性质 | 无影响，Agent 不依赖具体软件 |
| `timer_plugin` | 定时触发插件名，供人配置参考 | 无影响 |
| `hub_root` | 任务中枢根目录绝对路径 | 用当前工作目录 |
| `default_project` | 默认目标项目根目录 | 任务必须自带 `project`，否则子智能体报 blocked |
| `convention_file` | 目标项目约定文档的文件名 | 默认 `AGENTS.md` |
| `fallback_to_defaults` | 约定文档缺失时是否用默认约定继续 | 默认 `true` |
| `max_tasks_per_turn` | 单轮任务数上限 | 默认 3 |
| `summary_file` | 跨轮摘要文件名 | 默认 `_上轮摘要.md` |

## 默认约定（约定文档找不到时使用）

当目标项目根目录**没有** `convention_file` 指定的文档，且 `fallback_to_defaults: true` 时，子智能体按以下通用约定执行：

- 遵循目标项目现有代码风格与技术栈，不擅自引入新框架或依赖
- 编译/测试/启动命令从项目自身配置推断（如 `pom.xml`、`package.json`、`Makefile`、`README`），找不到就在任务里说明并跳过该步
- 提交前确认改动仅限「关联文件」范围，不碰无关文件
- 同一问题修复不超过 3 次，无法继续则报 blocked 并写明原因
- 不执行破坏性操作（`rm -rf`、`git reset --hard`、`git push --force`）

这些是**兜底**，不是某个项目的真实约束。要让任务严格贴合某个项目，请在该项目根目录放一份 `AGENTS.md`（可用 `draft/_内置-生成项目约定文档.md` 任务自动生成）。
